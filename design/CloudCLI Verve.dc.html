Type and components
Type
Encode Sans → Schibsted Grotesk for all UI · Merriweather → Instrument Serif for display and panel headings, italic for emphasis, never bold · monospace stays for paths, diffs and terminal.
Body 15.5px/1.65 · small 13.5 · eyebrow 12 uppercase .14em · tabular numerals wherever counts stack.
Component swaps
PillBar + Pill → Verve Tabs
shadcn Button → Button primary · tonal · outline · ghost · danger
status pills → Badge in five tones
Dialog → Modal · bottom sheet → Sheet · toasts → Toast
form rows → Field + Input / TextArea / Select / Switch
Lucide tab icons → unicode marks ✓ ✕ ▲ ● ↳ ✦
Rules that change behaviour, not just colour
▲ Errors are amber
Red is kept for destructive and denied. The task board's red "cancelled" and amber "review" swap sides accordingly.
— Unknown is a dash
Missing counts, untracked line totals and absent progress render as a bare em-dash, never 0.
✓ Colour never alone
Every state carries a mark or a word too: ● working, ✓ done, ▲ waiting for you.
i Say what ran on its own
Tool cards state whether the software acted or is waiting: "Done automatically" versus "Waiting for you".
