# Icons

All five are drawn in one ink, `#7b848d`, which holds 3:1 on the night and the day ground. They are for `<img>` use only; in an interface use the Icon component, which draws the same paths in `currentColor`.

- `play.svg` — 12px filled glyph: start speaking. On the primary button at rest.
- `stop.svg` — 12px filled glyph: stop what is running. Replaces play on the same button.
- `mic.svg` — 16px grid, 1.4 stroke, round caps and joins: listen through the microphone.
- `upload.svg` — 16px grid, 1.4 stroke: pick an audio file.
- `chevron.svg` — 16px grid, 1.4 stroke: the select's affordance (added for the custom select).
