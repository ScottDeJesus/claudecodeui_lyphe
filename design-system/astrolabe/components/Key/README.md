# Key

A keycap: the key that reaches something.

- **Provide** the key as `children`, in the system's own glyphs: ⌘, ⌥, ⇧, ↵, ↑↓, Esc, a letter or a digit. `pressed` while it is held.
- Pair it with the word for what it does, in mono beside it: "↵ Open", "Esc Close".
- Keys are hints, never decoration: show one only where the key works right now.
