# Notice

A one-line system notice in `accent` mono, centred above the transcript.

- **Provide** one sentence as `children`: cause first, then the remedy, joined by an em dash — "Microphone blocked — allow it in the address bar."
- Sentence case, no exclamation marks. It is a `role="status"` region.
- Clear it when a new action starts; the instrument drops it after 7 seconds.
