# Footprint

The companion's sign on anything it did — the core in miniature, a chrome bead in its orbit — so its work is always seen and never mistaken for yours.

- **Place** it on the thing itself: a message it sent, an answer it gave, a card it prepared, a memory it kept. Optionally one word of what it did as `children`: Answered, Sent, Prepared, Kept.
- `by` is the companion's name, read to assistive tech after the word ("Answered by Kaylee"). `size` (14).
- The bead is the only place outside the Core where the `chrome-*` ramp appears: it is the core, small.
- Never replace it with the companion's name or initial as a label, and never put it on your own words.
