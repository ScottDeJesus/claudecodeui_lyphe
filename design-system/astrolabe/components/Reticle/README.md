# Reticle

The companion's attention: corners that sweep in and close on whatever it is reading or about to touch, so you always see where it is.

- **Wrap** the thing it attends to and set `active`. The corners sweep in on `ease-lock`; `locked` closes them tight when it commits — a question taken, an action locked.
- `label` puts what it is doing on a plate above, in `canvas-plate` caps: "Reading · Bugfixes", "Answered".
- `tone`: `accent` for the companion, `secondary` (ice) for a helper it started.
- `sweep: false` closes the corners in without the turn. Use it round anything as wide as the page, such as a row in a transcript: a turn of that length would cross everything near it.
- One reticle per agent at a time: attention moves, it is never in two places. Take it off the moment the attention moves on.
