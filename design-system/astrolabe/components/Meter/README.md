# Meter

One measure, small: a ring with its figure inside. It is for a list where every row has the same measure, so the rings stand in one column and compare in one look.

- **Provide** `value` (0 to 1) and `label`, its name for assistive tech. `value: null` is no reading: the track alone and an em-dash, never a zero.
- `warn` and `danger` are the figures it turns at, judged on the rounded figure that is printed. Below both it is quiet: a measure is not news until it is high.
- `caption` goes under it ("wk · 3d"); `title` carries the whole reading for a pointer; `valueText` says it in words ("63% used").
- Give every row its ring in the same place so they line up. It can stand for the row's own mark: an account is its week.
- One measure shown large is the ArcGauge dial, never a bar: usage by window is a row of dials. The measure a thing wears all the time is the gauge round the core of its Hoop.
