# Orbit

What is waiting, as beads on the core's orbit: each arrives on the lobe and leaves on the settle, and the orbit drifts while anything waits.

- **Provide** `count`; `max` beads (8) before the rest show as "+N"; `size` (64). The count is in words for assistive tech ("3 waiting").
- It is a count without a number, for the one place with no rings to carry the same fact: a launcher small enough that only a core fits. Wherever there are Rings, the marks that turn `accent` already say what waits and which thing it is, so Orbit must not appear beside them.
- The orbit turns at the instrument's idle drift, and only while something waits. Beads are `accent`: what waits, waits for you.
